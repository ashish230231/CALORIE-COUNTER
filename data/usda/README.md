# Offline USDA data (optional)

The app downloads the USDA FoodData Central datasets automatically on first start.
If the machine has no internet access, download these files elsewhere from
<https://fdc.nal.usda.gov/download-datasets> and place them in this folder:

- `FoodData_Central_foundation_food_csv_2026-04-30.zip`
- `FoodData_Central_sr_legacy_food_csv_2018-04.zip`
- `FoodData_Central_survey_food_csv_2024-10-31.zip`

Then press **Retry import** on the Settings page (or restart the stack).
